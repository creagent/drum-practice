# Ритмика — этюды и акценты

Объединённое приложение: https://creagent.github.io/drum-practice/

Две вкладки на HTML, CSS и JavaScript. Ноты рисуются в SVG без нотного стана и внешнего нотного движка; звук синтезируется в браузере. Библиотеки, сервер и платные сервисы не нужны.

## Этюды

- 1–64 такта, размер 4/4.
- Для генерации выбираются ноты и паузы пяти видов: восьмые, триоли, шестнадцатые, квинтоли и секстоли.
- Общий ползунок пауз: 0, 5, 10 … 95, 99%. При 0% пауз нет; длительности с выключенной галочкой пауз их не получают.
- Отдельный ползунок акцентов: 0–100% с шагом 5%, по умолчанию выключен. Задаёт вероятность акцента на каждой ноте при следующей генерации; при 100% акцентированы все ноты. Паузы не получают акцентов. Знаки `>` сохраняются в PDF и SVG; при включённых акцентах отмеченные ноты звучат громче остальных.
- Восьмые ноты с точкой включаются отдельной галочкой для генерации и объединения. При разделении длинного интервала по долям восьмая нота с точкой может автоматически завершить начатую долю. Восьмые и четвертные паузы с точкой используются автоматически при объединении, независимо от галочек.
- Упрощение записи не зависит от выбора исходных длительностей: например, шестнадцатая нота и шестнадцатая пауза превращаются в восьмую. Половинные и четвертные возникают только при объединении. Отдельные удары и их время сохраняются. Границы долей важнее количества знаков: длительность, начавшаяся внутри четвертной доли, не пересекает её конец. У протяжённого барабанного знака остаток после границы записывается паузой без нового удара. Длинные знаки, начинающиеся на границе доли, сохраняются. Границы групп и тактов не пересекаются.
- Внутри триолей, квинтолей и секстолей могут смешиваться ноты и паузы. По умолчанию включены только восьмые и шестнадцатые ноты и паузы.

## Акценты

Сохранены параметры исходного генератора: 1–64 доли в такте, 1–64 позиции в доле, максимум акцентов от 1 до числа позиций, 1–256 тактов.

В каждой доле выбирается от одного до указанного максимума разных акцентов. **Все позиции — ноты, акценты обозначаются знаком `>` сверху.** Ноты соединяются в группы внутри доли. Все позиции сохраняются без объединения. Одна доля всегда равна четверти; например, три доли дают размер 3/4. Деления, не являющиеся степенями двойки, обозначаются скобкой с числом. У коротких нот соответствующее число рёбер и флажков.

Раздел «Позиции акцентов цифрами» сохраняет исходный формат и копирование. Например, `[13-2-2-23]` задаёт первую и третью позиции в первой доле, вторую во второй и третьей, вторую и третью в четвёртой. При количестве позиций больше девяти используются запятые: `[1,10-2]`.

## Общее для вкладок

- Светлая и тёмная темы. Первый запуск следует системной теме, ручной выбор сохраняется на устройстве.
- При переходе между вкладками сохраняются их настройки и сгенерированные упражнения. Переключение останавливает воспроизведение. Прямые ссылки: `#etudes` и `#accents`.
- На экране до 700 px — один такт в строке. На широком экране — два или четыре. Очень плотные такты акцентов прокручиваются внутри строки, а большие упражнения показываются частями. Воспроизведение автоматически открывает нужную часть.
- «Слушать» играет ноты в темпе 40–240 BPM; паузы молчат. В акцентах звучат все позиции: выбранные громче, остальные тише. Доступны метроном, громкость, остановка и подсветка текущей позиции.
- PDF скачивается напрямую: белые страницы A4 с нотами 300 dpi. SVG — один векторный файл. Оба экспорта содержат всё упражнение и не зависят от темы.
- После надписи «Готово к работе без интернета» приложение доступно офлайн, пока браузер хранит кэш. Можно добавить его на главный экран телефона. При открытии `index.html` как локального файла основная работа не требует установки.

## Проверки

Запустить из папки проекта:

```sh
node tests/generator.test.cjs
node tests/simplification.test.cjs
node tests/rest-chance.test.cjs
node tests/playback.test.cjs
node tests/pdf.test.cjs
node tests/accents.test.cjs
node tests/etude-accents.test.cjs
```

Проверяются 1023 сочетания галочек этюда с точками и без, длины тактов, неизменность ударов при объединении, все деления акцентов от 1 до 64, разные размеры, соответствие нот цифровым позициям, звуковой план, завершение и отмена воспроизведения, PDF и пагинация. В браузере проверяются вкладки, сохранение результатов, общая тема, мобильная раскладка и скачивание.

## Публикация

GitHub Pages публикует корень `main`; сборка не требуется. Кэш имеет отдельный префикс `rhythm-practice-` и не затрагивает два исходных приложения. При обновлении кэшируемых ресурсов увеличивайте версию в `sw.js`.

Объединены [генератор этюдов](https://github.com/creagent/drum-etude-generator) и [генератор акцентов](https://github.com/creagent/drum-accent-generator). Их опубликованные версии остаются самостоятельными приложениями.
